# TYPE & SURVIVE — Portfolio Code Samples

Unity와 C#으로 개발한 개인 프로젝트 **TYPE & SURVIVE**의 대표 구현 코드입니다. 화면에 동시에 나타나는 여러 적의 단어를 입력해 마법을 발사하는 생존 게임이며, 영어와 한국어 타이핑을 하나의 진행 규칙으로 처리했습니다.

## 핵심 구현

### 영어와 한국어를 공유하는 타이핑 흐름

영어 입력은 문자 단위로, 한국어 입력은 물리 키를 자모로 변환한 뒤 처리합니다. 입력 형식은 다르지만 이후에는 같은 순서로 모든 활성 타겟의 진행도를 비교합니다.

```text
키 입력
  ├─ 영어: 문자 정규화
  └─ 한국어: 물리 키 + Shift 상태를 자모로 변환
          ↓
활성 타겟의 입력 전 진행도 저장
          ↓
수용 가능한 타겟은 진행 / 진행 중 불일치 타겟은 초기화
          ↓
전역 오타 판정
          ↓
단어 완성 이벤트로 공격 대상 전달
```

### 한글 음절을 실제 키 입력 단위로 분해

완성형 한글의 유니코드 값을 초성·중성·종성 인덱스로 분해했습니다. `ㅘ`, `ㅝ`, `ㄳ`, `ㄺ` 같은 복합 자모는 실제 두벌식 키 입력 순서에 맞게 다시 나눕니다. Shift 조합도 별도로 변환해 `ㄲ`, `ㅆ`, `ㅃ` 등의 입력을 구분합니다.

예를 들어 `곽`은 화면에는 한 글자로 표시되지만 판정에서는 `ㄱ → ㅗ → ㅏ → ㄱ` 순서로 처리됩니다.

### 여러 타겟 사이의 입력 모호성 처리

같은 첫 글자를 가진 적이 여러 개일 수 있어, 하나의 입력을 모든 활성 타겟에 동시에 대조합니다. 진행 중이던 타겟이 입력을 받지 못하면 해당 타겟만 초기화하고, 다음 조건을 모두 만족할 때만 전역 오타로 판정합니다.

- 불일치가 발생한 타겟의 기존 진행도가 2 이상
- 입력을 수용한 다른 타겟의 새 진행도가 불일치 타겟의 최대 진행도보다 크지 않음

첫 글자만 같은 다른 단어를 선택한 상황이나, 더 많이 진행된 유효 타겟이 존재하는 상황은 전역 오타에서 제외합니다.

### 한글 진행도의 화면 표시

판정은 자모 단위로 수행하지만 화면 강조는 완성된 음절 단위로 표시합니다. 각 음절을 구성하는 자모 수를 계산해 현재 입력으로 완성된 글자까지만 색상을 변경합니다.

### 입력과 전투의 결합 분리

`WordTarget`은 단어 진행 상태만 관리하고, 완성 시 `WordCompletionEvents`로 대상의 `Transform`을 전달합니다. 플레이어 전투 로직은 이 이벤트를 구독해 대상을 공격하므로 타이핑 판정이 전투 구현에 직접 의존하지 않습니다.
